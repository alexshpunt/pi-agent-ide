# `pi-agent-read` documentation

This directory defines the platform contracts for the agent-facing `read` extension and explains how to extend it.

## Reading order

1. [`north-star.md`](/agent/src/extensions/pi-agent-ide/extensions/pi-agent-read/docs/north-star.md) defines the platform boundary.
2. [`tools/tool-read.md`](/agent/src/extensions/pi-agent-ide/extensions/pi-agent-read/docs/tools/tool-read.md) defines the public `read` contract.
3. [`plugins/plugin-protocol.md`](/agent/src/extensions/pi-agent-ide/extensions/pi-agent-read/docs/plugins/plugin-protocol.md) defines plugin registration and execution.
4. [`plugins/prompt-contributions.md`](/agent/src/extensions/pi-agent-ide/extensions/pi-agent-read/docs/plugins/prompt-contributions.md) defines plugin prompt descriptions.
5. Pipeline documents describe focused plugin patterns and testing.
