# Editing regression checks for 0.8.1

## Source and scope

Checked the four milestone bugs against develop commit `10e220a5dd014103af50be11b242bbe36e779df8` and the regression coverage in this PR.

The retained failures came from installed development package `0.0.0-dev.1787386127`, whose source commit was not recorded. All captured calls pass on the current source. The editor already contains the line-ending, EOF, transaction-sentinel and mutation-scheduling protections. This PR adds regression coverage; it does not claim a new runtime fix for an already-correct path.

LPT-700 is outside this scope. Original benchmark files were only read, never changed. Raw trajectories and private paths are not included here.

## Deterministic real-Pi replay

A temporary local scenario loaded the current IDE and native Codemode, without a model. It replayed captured arguments on original or immediate pre-call file snapshots. Formatting, lint and language-server plugins were disabled in the test-owned workspace so they could not change the byte contract. The stale-anchor plugin stayed enabled.

All 17 checks passed:

- LPT-698: six Markdown replacements, including Arabic, Chinese, Latin and mixed-script content, match the authoritative fixture's expected bytes.
- LPT-699: the two-insert group and four three-delete groups match the authoritative expected files. Every requested insertion or deletion persists; no extra EOF LF appears.
- LPT-704: both recorded insert/undo scenarios restore their immediate pre-edit bytes through standalone and native Codemode routes, four checks in total.
- LPT-705: both captured final-line/final-block calls succeed on their immediate pre-call snapshots and change only the requested bytes.

These are offline tool-pipeline checks, not benchmark grades or model-capability results.

## Retained regression coverage

`tests/integration/editing-byte-contracts.integration.test.ts` checks exact replacements and deletions, LF/CRLF and unterminated EOF, already-terminated and partial-line selectors, and full-plugin undo through standalone and native Codemode. Its parallel cases use real overlapping native calls, path aliases and a controlled tool-call barrier. They check disk bytes, committed per-call states and the native terminal output.

`src/extensions/pi-agent-text-editor/tests/core/exact-selection-endpoints.test.ts` connects the real document parser, exact resolver, registry and byte ranges. Valid EOF endpoints pass; invalid virtual-line endpoints fail.

`parallelWith` in the capability route validator requires an earlier execution to remain active in the same Codemode parent. Sequential calls, different parents and failed completions cannot establish parallel success. Its new unit test failed before the validator change and passes afterward.

Focused checks passed:

- 51 unit checks across the endpoint, parallel-route, resource-scheduler, post-edit, mixed-range and capability-validator files.
- 10 real-Pi integration checks across the new byte contracts and existing last-transaction restoration/guard scenarios.
- `pnpm check:capabilities`: 15 live tools, 157 capabilities, 74 cases; no model calls.
- Typecheck, lint and formatting of affected non-fixture files, the machine-path check after temporary-loader cleanup, and `git diff --check`. Fixture source is excluded by the repository lint/formatter defaults; its real extension launch and integration checks passed.
- Normal configured startup: one worktree IDE entry, no startup errors or warnings, no prompt.

The first integration attempt had three final-viewport assertions fail because earlier output had scrolled off screen; its byte and commit checks passed. The final test reads the concurrent result explicitly and uses enough terminal rows for its postflight reads. The final run passes without changing editor behavior or expected bytes.

## Live checks

The parallel deletion diff shows all three removals, with no false stale-anchor error or extra blank-line deletion. This is an internal visual check, not a user review substitute.
