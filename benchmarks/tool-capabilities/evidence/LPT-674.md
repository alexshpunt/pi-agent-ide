## Behavior

Compact is the default. The wrapper delegates Pi's native call summaries, hides collapsed JavaScript and successful printed output, and leaves errors visible. Separate retained IDE entries hide successful panels while collapsed but keep failed panels actionable. Expansion restores the original code, output and retained panels.

`ui.codemode` is registered in the existing settings menu. Compact stores `compact`; Detailed stores `full` and restores native previews. Project overrides Global. Default removes only the selected scope's override. No tool definition, execution path, model result or saved source is replaced.
