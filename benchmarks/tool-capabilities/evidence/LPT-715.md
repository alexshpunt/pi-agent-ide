## Confirmed failure and fix

The direct oversized-error case failed in CI run [37991576323](https://github.com/alexshpunt/pi-agent-ide/actions/runs/37991576323) and on current develop. The local provider request received 240219 bytes of saved blocked Replace feedback against a 51200-byte useful-text budget.

The shared wrapper marked a call ID after limiting an earlier reason. A later `message_end` handler replaced its content with the original guard. The provider boundary trusted the old mark and skipped the changed content. Compaction preceded the failing request but was not established as its cause.

The obsolete ID-only exemption is removed. Finalized unpublished errors and provider errors use the same limiter. Its cache checks the actual content version and reuses the already bounded version without truncating retention notices again. Registered result envelopes and saved records stay unchanged.

Removing only the exemption made provider checks pass but left the finalized result oversized. That partial attempt remains a failure. Limiting both surfaces made the existing direct and nested regressions pass.

The older editing evidence also failed the unchanged release-hygiene rule for a development-version literal. It now describes the development build by its ending identifier and keeps its source explicitly unrecorded. This does not regrade historical failures or weaken the scanner.
