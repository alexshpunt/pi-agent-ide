## Delivered behavior

`docs:ide-settings` is generated from the same module, flag, preference and preset registrations as the settings menu. Its JSON catalog gives supported values and defaults, not a live configuration snapshot. Its scope guidance explains storage, inheritance, module restrictions and legacy flags. It is read-only and searchable through the existing docs protocol, without editable Search references.

The packaged `configure-agent-ide` skill uses this catalog and actual saved scope files. It asks about ambiguous requests, preserves unrelated fields, distinguishes Default from an explicit default value, and reports pending reload. With documentation disabled, it points to installed configuration documentation and registrations rather than enabling unrelated modules. This paragraph describes intended skill behavior; independent model execution remains pending below.
