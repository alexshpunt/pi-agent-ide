It is read-only and searchable through the existing docs protocol, without editable Search references.

The packaged `configure-agent-ide` skill uses this catalog and actual saved scope files. It asks about ambiguous requests, preserves unrelated fields, distinguishes Default from an explicit default value, and reports pending reload. With documentation disabled, it points to installed configuration documentation and registrations rather than enabling unrelated modules.
