# Linear AXI backend

This private workspace contains Pi Agent Linear's fork of [Linear AXI](https://github.com/nikolauska/linear-axi/tree/v0.3.1). The copied upstream source is MIT-licensed; see [LICENSE](LICENSE).

Pi Agent Linear runs the compiled `dist/bin.js` CLI and `dist/worker.js` through this package. The plugin manages authorization and exposes the agent tools. Do not enable or publish this backend as a separate Pi package.
